# Testes

`tools/check-project.mjs` é a checagem de contrato que pode ser executada sem toolchain embarcada:

```powershell
node tools/check-project.mjs
```

Testes de unidade do PlatformIO e o protocolo na placa estão planejados para depois que o PlatformIO Core estiver disponível. O roteiro físico que deve acompanhar qualquer build está em [`docs/VALIDATION.md`](../docs/VALIDATION.md). Nenhum teste é marcado como executado antes de haver resultado observável.
